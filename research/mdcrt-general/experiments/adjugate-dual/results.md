# 伴随矩阵归约与对偶格 HNF

`AdjugateDualMDCRT` 处理任意一组同维非奇异整数模矩阵。输入为各模矩阵和对应的整数余数向量。`solve` 返回一个整数特解，或者在无解时返回 `None`。`B` 的列是完整齐次解格的基。

```python
from mdcrt_adjugate_dual import AdjugateDualMDCRT

solver = AdjugateDualMDCRT([[[2, 0], [2, 6]], [[2, 0], [4, 10]]])
x0 = solver.solve([(1, 5), (1, 1)])
B = solver.B
```

## 等价归约与完整性

令 `g` 为全部模矩阵元素的正 gcd。所有余数必须同模 `g`。取其公共余数代表 `c`，置 `x = c + g*y`、`N_i = M_i/g`、`s_i = (r_i-c)/g`。第 `i` 块约束等价于

\[
\operatorname{adj}(N_i)(y-s_i)\equiv 0\pmod{|\det N_i|}.
\]

逐行除以系数和模数的 gcd，删掉模数为 1 的恒真行。如果某一行约简后仍有模数 `abs(det(N_i))`，这条原始模数的本原同余的核格已经具有 `abs(det(N_i))` 的指数。由于它包含 `N_i Z^n`，且指数相等，两格相等，因此此块只保留该行。其他块保留全部有效行。最终得到 `a_j y ≡ b_j (mod d_j)`，其中 `b_j = a_j s_i`，`i` 为原行所属的块。

令 `D` 为所有 `d_j` 的最小公倍数，空集取 1。构造有理行格

\[
\Lambda=\mathbb Z^n+\sum_j \mathbb Z\frac{a_j}{d_j}.
\]

`D Λ` 是整数行格，令 `H` 为它的行基。齐次条件等价于 `H y ∈ D Z^n`，所以归约后完整齐次解格为 `D H^{-1} Z^n`，原系统完整齐次格基为 `B = g D H^{-1}`。这个矩阵是整数矩阵，因为 `D Λ` 包含 `D Z^n`。

每个块只包含至多 `n` 条有效标量约束。令 `D_i` 为前 `i` 块的行模数的最小公倍数。将前一格基乘以 `D_i/D_{i-1}` 后，与该块的行 `(D_i/d_j) a_j` 堆叠，求一次带变换行 HNF。每次 HNF 至多有 `2n` 行、`n` 列。其前 `n` 行形成新行基，整数变换的前 `n` 行也给出新基相对旧基和新增行的线性组合。

对这些变换使用相同的 RHS 线性组合，并统一到最终分母 `D`，即可预编译矩阵 `L`，使得任意可解右端都满足 `H y ≡ L(s_1,…,s_k) (mod D)`。求解时将右端约到模 `D`，再乘 `H^{-1}`。如果系统可解，这个候选必为整数，且与原解相差 `D H^{-1} Z^n` 中的向量。对候选检查全部原始标量同余即可判定相容性。最后返回 `c + g*y`。

## 验证与复现

当前实现依赖此前 MD-CRT 实验中的 `mlc_mdcrt_exact` 包和它加载的 FLINT。用相同的 Python 环境在本目录运行：

```powershell
python -B -m unittest -v test_mdcrt_adjugate_dual
python -B benchmark_mdcrt_adjugate_dual.py --out mdcrt_adjugate_dual_new_timings.csv
```

基线为原生全局堆叠 HNF 和矩阵级联，两者都预编译权重并输出特解及完整格基。转换、预处理和查询均计时。各配置使用三个种子，每种子重复三次。每个工作进程对计时后的全部特解代回原始矩阵同余，并以规范 HNF 比较各路线的周期格。独立测试另覆盖不相容、仅两两相容、负行列式、单位块、无公共因子和无法压为单行的矩阵块。

该算法的 HNF 维数随单块维度变化。整数位长还取决于模数的最小公倍数和中间系数，因此尺寸界本身只控制矩阵规模。对于小系统，转换和额外的固定成本可能占主导。
